# Changelog

## 0.9.0 — Open-source preview

- Added a standalone local Node.js launcher with automatic SQLite migrations and private PDF file storage.
- Preserved PDF import, editable broad categories, interactive relationships, annotations, text search and on-device translation.
- Added an isolated synthetic demo library with original generated PDFs.
- Added Chinese and English documentation, original branding assets, real interface screenshots and contributor templates.
- Excluded private records, deployment identities, author contact details and previous repository history.

This release is the local single-user edition. Public authentication and automatic cloud synchronization are planned separately.
